# image-captioning
AI Image Captioning using Python and BLIP Model

# CODSOFT Task 3 - Image Captioning AI

## Project Overview
This project is an AI-based Image Captioning application developed using Python.

It uses a pre-trained BLIP (Bootstrapping Language-Image Pre-training) model to understand images and automatically generate meaningful captions.

## Features
- Upload images from your computer.
- Preview uploaded images.
- Generate AI-based image captions.
- Copy generated captions.
- Clear images and upload new images.
- Simple and user-friendly GUI.

## Technologies Used
- Python
- Tkinter
- PyTorch
- Hugging Face Transformers
- BLIP Image Captioning Model
- Pillow

## Installation

### Step 1: Install Python
Download Python from:
https://www.python.org/downloads/

### Step 2: Install Required Libraries

Open the terminal and run:

```bash
pip install -r requirements.txt
```

### Step 3: Run the Application

```bash
python image_captioning.py
```

## How It Works
1. Upload an image.
2. The AI model analyzes the image.
3. The BLIP model generates a caption.
4. The caption is displayed on the GUI.
5. Copy the generated caption if needed.

## Model Used
Salesforce/blip-image-captioning-base

## Objective
To combine Computer Vision and Natural Language Processing to automatically generate meaningful descriptions of images.

## Conclusion
This project demonstrates how pre-trained deep learning models can be used for image understanding and automatic caption generation.
